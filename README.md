# odin-todo-list

## Overview
This project is a TODO list built with JavaScript, leveraging Webpack for module bundling and using localStorage for data persistence. It follows a structure similar to the Odin battleship project, providing a clean and organized way to manage tasks effectively.

## Features
- **Todo Management**: Create, update, and delete todos.
- **Projects**: Organize todos into different projects for better management.
- **Todo Properties**: Each todo includes properties such as:
  - Title
  - Description
  - Due Date
  - Priority
- **DOM Manipulation**: Dynamic updates to the UI without page reloading, allowing users to see changes instantly.
- **State Management**: Efficient management of the application state to ensure smooth user experience.
- **Persistent Data Storage**: Utilizes the Web Storage API (localStorage) to save todos, ensuring that data persists even after a page refresh.
